# EduSurvey - Design System & UI/UX Guidelines

Inspired by Apple Human Interface Guidelines, Vercel, Linear, and Raycast.

---

## 🎨 Aesthetic Core

1. **Glassmorphism**: `.glass-card` (`backdrop-filter: blur(16px); bg-white/70 dark:bg-slate-900/75`).
2. **Typography**: SF Pro / Inter font stack with generous whitespace and rounded corners (`rounded-2xl`).
3. **Color Palette**: Curated HSL Tailwind tokens (Primary Blue `#2563EB`, Emerald Green `#22C55E`, Amber `#D97706`, Slate Dark Mode `#020617`).
